# Minha Lista de Compras – Lumanoids (PWA)

Publicar no GitHub Pages: envie o conteúdo desta pasta para o repositório (raiz ou subpasta) e ative Pages.
Estrutura: index.html, css/style.css, js/app.js, js/catalogo.js, manifest.webmanifest, sw.js, icons/.

- Dados: localStorage do navegador (sem banco externo). Limpar dados do navegador ou desinstalar apaga a lista.
- Offline: sw.js guarda os arquivos. Ao alterar qualquer arquivo, aumente `VERSAO` em sw.js.
- Novos produtos no catálogo: edite js/catalogo.js.
- Android/Chrome: aparece o banner "Instalar" (ou menu ⋮ > Instalar app). iPhone: Compartilhar > Adicionar à Tela de Início.
