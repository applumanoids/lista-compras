# Minha Lista de Compras – Lumanoids (PWA)
Publicar: envie o conteúdo desta pasta para um repositório e ative GitHub Pages (branch main, pasta raiz).
Instalar no Android: abra o link no Chrome > "Instalar na tela inicial" (ou menu ⋮ > Instalar app).
Dados: ficam no localStorage do aparelho. Catálogo: edite js/catalog.js. Ao mudar arquivos, aumente a versão `V` em sw.js.
